# Product emails

Each file here is one email to the "Quality3Ds product news and offers" subscribers.

1. Copy `example-offer.md` to a new file, e.g. `2026-12-makita-mounts.md`, and edit it
   (GitHub: open the folder, **Add file → Create new file**).
2. Go to **Actions → Send product email → Run workflow**, type the file name and pick
   **test**. Only the Quality3Ds Gmail inbox gets it, with `[TEST]` in the subject.
3. Check it looks right, then run it again with **all**.

A file can only go to everyone once (`sent.txt` keeps the list). Gmail allows about
450 recipients a day in total, so don't send on a day the list is near that size.
This repo is public, so anything in this folder can be read by anyone.
